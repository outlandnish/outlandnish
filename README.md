# Hi there!

My name is Nishanth and I do technical strategy + engineering consulting at Blackbird Studios. I love working with mobility, travel, and/or anything related to how people get around.

### Projects I'm working on

- Subaru BRZ EV conversion
  - [tm3diag](https://github.com/outlandnish/tm3diag) - A diagnostics tool + firmware update tool for Tesla ECUs for use in EV conversions
  - [HV ECU](https://github.com/outlandnish/subaru-brz-hv-ecu) - An ECU to manage the HV system + BMS for Porsche Taycan battery modules
  - [BRZ VCU](https://github.com/outlandnish/subaru-brz-vcu) - A drop-in replacement VCU for my Subaru BRZ that replaces the OEM ECU
  - [NXP MC3377xb Driver](https://github.com/outlandnish/nxp-bcc-mc3377xb-driver/) - A driver for MC3377x battery cell controller chains
- Micromobility reference designs
  - A new open USB C VDM spec overlay for EN 50604 compliance (to be published)
  - Modular, travel friendly batteries with topology switching (to be published)
